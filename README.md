## Getting Started
To build the place from scratch, use:

```bash
rojo build -o "ToyGameRestoration.rbxlx"
```

Next, open `ToyGameRestoration.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

## Prototype de restauration

Le système utilise en priorité une `BasePart` du Workspace nommée `Console`,
`RestorationObject` ou `ObjectToClean`. Une Part nommée simplement `Part` est
également acceptée pour le prototype. Pour cibler explicitement une autre Part,
ajoutez-lui l'attribut booléen `RestorationObject` avec la valeur `true`.

En jeu, approchez-vous de l'objet et appuyez sur `E`. Maintenez le clic gauche
sur une salissure pour la nettoyer. Avec l'outil `Main`, cliquez sur l'objet
pour afficher le menu `Transformer`. Ce menu permet de faire tourner l'objet
sur ses axes locaux `X` et `Y` ou de verrouiller les transformations. Le bouton
`Retourner`, séparé du menu et placé en haut de l'écran, applique un demi-tour
avec n'importe quel outil. Après avoir choisi `Tourner`, maintenez
le clic droit : les mouvements verticaux contrôlent X et les mouvements
horizontaux contrôlent Y. Une seule direction est choisie au début de chaque
glisser et reste verrouillée jusqu'au relâchement. Le bouton `Retourner` remet
d'abord l'objet dans son orientation plate, puis alterne entre sa face et son
dos. Lorsque l'objet est verrouillé ou désélectionné, le
clic droit-glissé fait orbiter la caméra. Le clic molette-glissé, ou `Maj + clic droit`, déplace la vue à 
droite, gauche, en haut et en bas dans une zone limitée. La molette zoome vers
la position du curseur. Quand le menu Transformer est ouvert, l'objet est
soulevé pour pouvoir tourner sans traverser le sol. La caméra est bloquée devant
les sols, murs et autres obstacles. Le glisser tactile est également pris en charge. Les
touches `1` à `4` sélectionnent la main, la brosse, le chiffon et le coton-tige.
`Échap` quitte l'atelier.
